| 步骤 | 要做什么 | 关键材料 | 多久 | 费用 |
|---|---|---|---|---|
| ① 办执照 | 「粤商通」APP 全程网办个体工商户 | 身份证、经营场所证明（房产证或租赁合同+房东产权证）、字号 3–5 个、经营范围（系统勾选） | 材料齐全最快当天出电子执照，多数 1–3 天 | 登记免费；刻章约 200–500 元自理 |
| ② 小程序注册 + 微信认证 | 微信公众平台注册小程序（个体户主体），做微信认证 | 未注册过公众号/小程序的邮箱、执照、法人身份证、管理员微信扫码 | 认证审核 1–3 天 | **300 元/年** |
| ③ 小程序 ICP 备案 | 通过微信侧/腾讯云提交**主体备案**（新主体强制） | 执照 + 法人人脸核验 | 约 1–3 周（广东实际常 5–7 工作日） | 免费 |
| ④ 开微信支付商户号 | 认证通过后申请，个体户绑法人个人银行卡即可 | 执照、法人身份证、个人银行卡 | 审核 1–3 天 | 无开通费；费率约 0.6%（以签约页核定） |
| ⑤ 域名备案 | 把 huangqidong.cn 做**接入备案**（服务器接入商用腾讯云） | 域名证书（所有人与主体一致）、执照、法人身份证、视频核验、国内云资源 | 腾讯云初审 1–2 天 + 管局 ≤20 天 | 免费（需有国内云资源） |

> ⚠️ 关键提醒：huangqidong.cn 现在挂在 Cloudflare 且**没在国内备案**，而 Cloudflare 是境外服务商，没法给小程序当合法域名。所以要么把后端迁到腾讯云 CloudBase（支持备案自定义域名），要么小程序用微信云开发原生调用绕开域名备案。**这是历史裁定「后端迁 CloudBase」的落地理由，不是可选优化。**

## 四、小程序端现状盘点（截至 2026-09-22）

- `miniprogram/app.json` 里注册的页面是 `home / shop / community / mine / today / sales / inventory / more`——**这是旧的店员 ERP 小程序壳，不是顾客端**。与「网页是内部 ERP、小程序是顾客端」的方向相反，属历史遗留。
- 顾客端的核心需求（看专属报价、确认、付定金、查进度）**一行都没开始**：没有顾客登录授权、没有报价分享页（契约 Q-09）、没有下单支付闭环。
- 顾客端真正能开工，依赖三件事：①小程序主体（执照）→ ②顾客身份方案（微信登录）→ ③后端迁 CloudBase 或云开发原生调用。**这三件都卡在第一节的 5 步行政手续上。**
