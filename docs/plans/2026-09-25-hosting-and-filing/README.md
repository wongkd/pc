## 一句话结论

**服务器买什么不是关键，域名与备案的"主体"才是关键。** 因为小程序关联的备案域名必须和小程序主办者一致（个人备案 ↔ 个人主体，个体户备案 ↔ 个体户主体，**不能跨主体混用**），而 `huangqidong.cn` 目前是**个人主体**备案，所以必须先把域名和备案改到个体户名下，才能接小程序。

因此采用**组合方案**：省钱路线（域名过户 + 备案主体变更 + 自建轻量）为主线，同时保留"想提前跑通就先走免备案通道"的备选。

## 五、必须避开的 5 个坑

1. **主体一致**：小程序关联的备案域名必须与小程序主办者一致。跨主体混用会被驳回，驳回原因里明确出现过"备案号为个体户类型却用于公司主体"这类描述。
2. **域名实名也要一致**：域名注册人信息须与备案主体一致，否则备案核验失败 —— 所以"域名过户"和"备案主体变更"要一起做。
3. **Cloudflare 代理问题**：备案要求域名解析指向备案接入商的境内服务器。`huangqidong.cn` 的 DNS 在 Cloudflare，**`api.` / `erp.` 子域应走灰云直连**境内服务器；用橙云（CF CDN 代理）可能被核查为"未接入"而影响备案。
4. **可能被要求注销重备**：多数省份可走"变更主体"（备案号不变），但个别省份要求注销后重新备案，期间站点不可访问 —— **以广东省管局/接入商系统提示为准**。
5. **别用境外服务器**：国内版小程序不接受境外服务器托管的域名；Cloudflare Workers 虽然免费又好用，但不能作为小程序的 request 域名落点。
