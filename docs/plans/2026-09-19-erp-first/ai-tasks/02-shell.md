# 02 · ERP 壳与公共组件

日期：2026-09-19。状态：V2 待用户评审；现可做映射准备。对应 E03。入口：[分发说明](README.md)。
目标：把评审后的视觉变成 React 公共组件，保护现有登录、权限、深链与打印。

## 范围与依赖

读 [V2](../../../design/2026-09-19-erp-core/v2/README.md)、[UI/UX](../02-ui-ux.md)、[复用清单](../03-reuse-and-cleanup.md)。

本卡负责公共路由接线与设计令牌；样式限定新壳作用域，统一 `--erp-*`，不覆盖旧报价打印。
允许新建 `frontend/src/features/erp-shell/` 等独立目录；遵从现有目录约定，不新增框架。

## 分阶段

准备：逐项映射现有路由、权限、打印入口；列出要提取的按钮、面板、数据表、金额、状态、表单、抽屉、空/错误态。
实施：01 环境隔离且用户评审 V2 后开始；接真实会话，不放宽入口权限。
六项业务导航为工作台、销售、库存、维修售后、回收置换、收支；销售二级报价/订单，不把 E01 原型的四屏演示导航当最终信息架构。
搜索必须接已具备的读模型；未实现结果明确标识，禁止返回假业务数据。

## 必须交付

公共组件示例页覆盖长中文型号、六位金额、空/失败/无权限、待核实、不可执行原因。
抽屉 Escape 关闭、焦点返回；键盘可进入/退出；导航切换和返回恢复合理筛选/位置。
页面通过 props/域模型提供数据，组件不直接访问其他模块的内部状态。
原型 demo 入口与业务入口隔离，不能把固定演示收款当作真实接口。
