## 公共文件归属与交接协议

- 契约只由 01 的负责人改源文件并重新生成；其他 AI 提交契约需求清单，禁止手改 generated。
- `frontend/src/App.tsx`、`frontend/src/app/*`、公共样式由 02 负责人统一接线；模块 AI 交付页面导出与路由接入清单。
- `backend/src/index.ts` 是共享入口，由本阶段集成人员串行注册路由；模块按 domain 交付，不多人同时改大入口。
- 迁移编号必须由集成人员统一分配，先核当前最新编号和应用状态；不要各自都写 0010，不修改历史迁移。
- 原型各用独立目录与 CSS 作用域；06/07/08 不编辑 E01 的 v1/v2 文件。公共组件先复制最小展示样式或明确依赖，不引入独立生产框架。
- 当前工作区大量变更未提交。直接创建 worktree 不会包含它们；若要隔离，先由负责人准备准确基线/快照和迁移清单，不假定 HEAD 就是完整现状。
- 同一工作区不并行跑前端 test/build，不并行写同一文件。一个 AI 每次只领取一张卡的一个阶段。
- 回执至少包含：基线 HEAD、开始时相关脏文件、实际新增/修改范围、接口依赖、运行命令与退出码、截图或测试文件、剩余问题。集成人员先复核差异再合并，不能只信“全部完成”。

## 统一界面与数据约束

V2 是最新候选原型，用户只确认“彩色”和继续重做，尚未确认最终稿。后续原型沿用其字体、间距、卡片/表格与按钮尺度，允许按本模块任务改变布局。
金额整数分；顾客预算不算付款；新品/回收二手/客供逐行区分；未付款不预留不采购；交付才销售扣库。
成本未知用 null/待核实，不以零替代；无成本权限的读模型不返回成本/供应商/内部备注。前端隐藏不是授权。
真实动作超时进入结果待核实；同 requestId 回查，不重复收款/扣库。模拟动作必须标注演练，不返回伪成功。
