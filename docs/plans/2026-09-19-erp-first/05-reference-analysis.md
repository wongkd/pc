## 1. 为什么这些图比现有版本更有设计感

图中常见做法是：背景与面板有明确层级、字体干净、数字和标题有大小对比、同组控件对齐、留白成体系、强调色用量受控。
旧版截图里的问题则是米黄/浅绿/细线之间层次偏弱，衬线标题和小字显得像打印文档，筛选控件零散，大日期与设备图又压缩了操作空间。
重做需要同时改变排版、布局、密度、组件和操作路径；只换一个颜色无法解决这些问题。

## 3. 建议组合

**主方案：图 2 下的清晰结构 + 图 7 上的浅色质感 + 图 3 上的右侧处理区。**
图 5 上/图 7 下只在预约与排期场景借用；图 6 上是暗色可选方向，不因参考图中有深色就把主系统定成深色。

具体落成：

1. 六项中文侧栏保留文字，顶栏集中搜索和账号，工作区不加展示海报式厚外框。
2. 雾灰白背景、白色内容面板、石墨黑标题与主要按钮；少量冷蓝用于选中/交互，状态色有固定语义。
3. 工作台只保留少量业务数值，主体是可处理的任务列表，右侧有今日交付/预约与当前单据处理。
4. 报价页以配件编辑为主体，右边是实时结算和顾客预览；订单页以配置、备货、检测为主体，右边是钱和下一步。
5. 表格借图 2 下的秩序和图 3 上的状态表达，保持足够行密度；卡片只用于分区和摘要，不逐字段套框。
6. 中文页面重做字体与排版，不能把英文海报缩小字后硬塞进中文字段；长型号、金额和错误态一起设计。

## 4. 为什么不直接复制某一张

这些图多为统计/展示型概念稿，未展示真正 ERP 最难的报价编辑、分批到货、拆件成本、失败重试和版本冲突。
因此可以借视觉和结构，但必须用本店业务样本重做核心页面。判断设计成功的方式是既能看出新风格，也能完成 [UI/UX 任务验收](02-ui-ux.md)。

当前只推荐组合，不代表用户已经选择颜色、浅/深主题或具体布局。
下一份设计交付应给实际中文高保真可点击页面与核心操作，不能再拿旧版截图声称新设计完成。
