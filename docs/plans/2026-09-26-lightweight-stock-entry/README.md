# 小店轻量化现有库存登记

- 日期：2026-09-26
- 状态：代码已提交并发布到生产合并版；后端与前端自动化检查、生产构建通过；本轮未做生产登录后的页面/业务验收。详见[合并发布回执](../../verification/2026-09-26-consolidated-release/README.md)。
- 目标：让 1–3 人使用时能直接建商品、登记已有库存，不必开启限时窗口或填写内部盘点编号。
- 入口：ERP → 仓库 → 新增商品 / 登记现有库存。

## 当前流程

1. 商品随时可建，默认库存为 0。
2. 新增商品时可选填店里已有数量；商品先保存，库存随后登记。库存登记失败时保留商品并显示可继续处理的提示。
3. 仓库入口可以随时登记已有库存。系统自动生成内部登记编号、记录操作人和时间。
4. 新进货继续走采购到货；已有库存事实的商品不重复做现有库存登记，数量差异走实盘处理。
5. 成本留空表示未知，0 表示真实零成本；正数可以选择实际或估算，估算日期自动记录，说明备注可选。
