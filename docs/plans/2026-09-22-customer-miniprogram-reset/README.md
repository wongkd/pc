## 最省事的使用方法

1. 双击[任务选择器 index.html](index.html)，从 **MP00** 开始。
2. 点“复制完整提示词”，粘给能访问本仓库的 AI；每次只做一张。
3. 让 AI 完成本卡检查和回执；再选下一张。前置没过就修当前卡，不跳过验收。

复制按钮不可用时点“全选文本”，按 Ctrl+C；也可直接发送[MP00 文件](tasks/MP00.md)。
这是离线提示词工具，不启动业务服务、不修改文件，也不自动判定完成状态。

## 分批交付

| 阶段 | 卡号 | 结果 |
|---|---|---|
| 先把四屏做对 | MP00–MP15 | 素材清单、令牌、组件、逐块还原四 Tab、首次截图放行 |
| 身份与公开内容 | MP16–MP25 | 隔离环境、顾客登录、ERP 发布商品/案例/首页、小程序真实读取 |
| 顾客详情与报价 | MP26–MP35 | 商品/文章/门店详情、分享授权、我的报价、查看与确认 |
| 订单与服务 | MP36–MP55 | 订单、意向与照片、ERP 处理、售后/回收、档案与设置 |
| 真实支付 | MP56–MP59 | 前置核实、预支付、服务端通知/对账、支付结果恢复 |
| 最终验收 | MP60–MP64 | 发布隔离、微信工具看图、双端闭环、安全、真机、候选交接 |

大部分界面卡适合轻量 AI；顾客授权、分享、契约与支付卡需要重点复核。
任务数多是为了每次改动小；不能把 65 张一次性发给小模型让它整项目自由发挥。
