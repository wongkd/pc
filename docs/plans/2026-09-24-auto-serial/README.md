# 自动编号与统一追溯方案

日期：2026-09-24。状态：按用户确认实施首版源码；未运行测试、未做浏览器验收、未应用迁移。
目标：所有需要识别实物的业务自动取得内部编号，按编号查到实物、来源、去向及关联单据，消除重复手填。
入口：本文；实际状态见 [STATUS](../../STATUS.md)，下一动作见[交接](../../NEXT-SESSION-PROMPT.md)。

## 1. 已确认规则与首版边界

1. 内部编号由服务端自动生成；厂家 SN 独立存储、可选扫码录入，并支持备注。
2. 线材等按数量管理的耗材按批次编号并支持备注；首版只记录批次入库数量，不显示剩余批次量，因为当前库存流水没有按批次扣减归属。
3. 当前查询通过员工库存页按内部编号、厂家 SN、备注、批次号查询；旧 SN 台账继续服务原有保修与订单绑定流程，不把旧表记录直接当作库存。
4. 首版未实现二维码/标签打印，也未做历史 SN 自动迁移；打印和历史映射作为后续范围。

用户已确认第 1、2 项。顾客侧查询范围及标签打印设备尚未确认，首版不对顾客开放内部编号查询。

## 3. 首版编号与身份设计

- 内部编号示例：`IT-0001-20260924-A1B2C3D4E5`（逐件实物）、`BT-...`（耗材批次）、`DV-...`（客户设备），包含类型、门店、上海日期和随机后缀；不编码价格、客户电话、商品种类或所有权等可变信息。
- 所有实体主键继续使用现有 ID；新增统一身份注册表与来源映射，关联 stock_items、客户设备、回收接收物、批次及旧 SN。一个实体唯一绑定一个身份，允许一项身份关联同一实物的多个生命周期记录。
- 编号由服务端分配，门店级数据库唯一约束兜底；随机后缀避免并发计数器。极低概率唯一冲突当前会由数据库拒绝，未实现自动重试。
- 生成与业务提交纳入现有幂等操作机制。同 requestId 重试返回原对象与原编号；超时先查操作结果，不能用新请求再次生成。
- 默认只读、创建成功才展示正式编号。纠错通过有权限的修订动作与审计，旧号码保留为可查询别名，不静默覆盖。
- 单件从入库到售出、退货、维修、再回收保留身份。整机与配件各有身份，通过配置版本关联；换件仅改变关系，拆出新识别实物建立父子来源关系。换客户不换号。
- 厂家 SN 继续保存原值与规范化索引，明确缺失/已登记状态；不能拿内部编号填 sn_raw 来绕过校验。既有去重规则先保持，遇到历史冲突进入人工处理清单。

## 4. 全业务覆盖目标与当前接入

下表是完整追踪目标，不代表首版全部接通。已接入首版代码的入口为期初、采购到货、维修设备建档、回收取得所有权和拆件产出；其他场景沿用现有库存实物 ID/编号或待后续补齐身份关联。

| 场景 | 生成/复用时点 | 关联与查询 |
|---|---|---|
| 期初库存与采购到货 | 逐件正式建档成功时自动分配；批量 n 件返回 n 个号码 | 首版已接入；批次只有初始收货量，尚无剩余量归属 |
| 数量耗材 | 按确认的粒度建批次或单件身份 | 首版建批次记录和可查询批次码；分次出入库与剩余量待实现 |
| 报价和销售 | 草稿、缺货意向不制造实物；实际选件复用编号 | 报价/销售引用、占用与释放，不额外增加库存 |
| 装机交付 | 整机设备首次正式建档生成整机号，组件复用原号 | 交付沿用库存实物 ID；独立设备号与配置时间线待补齐 |
| 客供件与暂存 | 首次接收建档，已有设备选择原身份 | 首版未新增统一映射 |
| 维修接修与换件 | 首次设备建档生成，复修复用；新备件引用库存号 | 接修已生成设备编号并可按编号/SN 查工单；换件沿用现有库存关联 |
| 回收估价与收购 | 首次实物接收建档；远程估价不凭空创建在库实物 | 取得所有权时生成内部编号；收购前暂存设备仍以回收单追溯 |
| 拆机、整备与再销售 | 已有配件身份复用；新识别拆出件生成 | 拆件产出自动生成内部编号；完整母子链详情待完善 |
| 退货、报损、盘点 | 复用原编号，不重新生成 | 逆向流水、差异、位置及终态，作废号码仍能追溯 |
| 老客户补录与历史 SN | 经预检给已有记录补身份映射 | 保留旧 SN、老号码和历史保修事实；未知来源标记未知 |

## 5. 查询与页面

- 首版在员工库存页提供内部编号、厂家 SN、备注、批次号搜索；售后列表可按设备编号、厂家 SN、工单号搜索。旧 SN 台账目前仍是独立保修/订单绑定入口，后续再评估兼容映射，不将两套记录混作一套库存。
- 结果标明实物/整机/批次/历史记录类型，显示状态、位置、归属、来源与业务链接。一个厂家 SN 命中多项时列出候选，禁止默认绑定第一项。
- 首版支持从库存搜索结果打开逐件库存详情；跨采购、装机、交付、维修、回收、拆件的统一时间线和其它页面跳转待后续完善。
- 期初、采购到货、回收取得/拆件的逐件录入显示“提交后自动生成”，厂家 SN 可选；维修接修设备号由服务端自动生成。
- 查询在服务端限制门店与业务权限；成本、供应商、客户资料按原有权限裁剪。未登录扫描不返回内部信息，二维码不含个人信息或成本。
- 处理加载、空结果、无权限、重复码、失败重试和结果未知；打印失败只重打同一编号，不重复建档。
