# A4 报价打印最终版样稿

日期：2026-09-25。状态：用户确认字段结构、质保规则及 24 小时有效期口径；正式打印代码已按此实现。

## 入口与示例

版式样稿：[index.html](v1/index.html)。展示一张 A4 纵向报价单。示例日期为 2026 年 9 月 25 日 10:30，有效至 9 月 26 日 10:30，体现报价日期起算 24 小时。

示例行是虚构内容：CPU / Intel Core i5-12400F / 二手 / 数量 1 / ¥320.00 / 成色九成新。15% 预付款仅为展示样例，正式打印使用报价条款中的比例。

## 正式实现

正式报价打印模板位于 `frontend/src/features/workbench/WorkbenchQuotePage.tsx`：A4 页面；配置明细分开显示配件、型号、来源、数量、单价、小计、顾客可见备注；质保说明、金额、定金及交付条款在明细下方。有效期对已发出版本取服务端签发的 `validUntil`，草稿预览以版本报价时间加 24 小时显示。

报价编辑器允许逐行录入顾客可见备注，并把备注放入已存在的 warranty snapshot JSON 字段，不修改跨端契约或数据库结构。内部备注、成本、供应商、SN 不进入顾客打印视图。

质保规则按D07 R1.2：新配件基础店保1年、二手配件1个月、客供安装工艺90天；全二手整机可选3/6个月总保障期延保，费率5%（最低99元）/8%（最低159元），按比例计算向上取整到整元。法定责任及适用的厂家/本店更优承诺继续保留。预付款与退款按经营规则，不写“定金不退”。独立延保选择、收费和订单履约流程仍未接通，不能标记为已购或据此收款。
