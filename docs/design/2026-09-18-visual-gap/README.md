## 验收标准与运行命令

- 桌面至少 1366×768、1440×1000；同视口对照设计稿，保存完整截图。检查无横向溢出、主动作首屏可见、图像正常、长名称与金额不挤压。
- 验证筛选、搜索无结果、切换事项、列表/看板、图片失败、键盘焦点与禁用操作；金额、选中项、阻断条件不因换布局改变。
- 网页修改后按范围执行 `npm --prefix frontend run test`、`npm --prefix frontend run build`；只报告实际执行结果，既有失败单列。
- 若修改小程序，执行 `npm --prefix miniprogram test`、`npm --prefix miniprogram run typecheck`、`npm --prefix miniprogram run check-pages`、`npm --prefix miniprogram run check-classes`，并单列模拟器/真机结果。
- 只有涉及契约消费、两端口径或请求行为的修改，才追加相应契约与跨端门禁；本轮纯文档交接不运行业务测试。

不得部署、迁移远端数据库、混合提交现有工作。演示产物仍不得作为可用业务版本发布。交付时说明“哪些地方已对齐、哪些仍缺业务数据、实际验证了什么”，不能用 build 通过代替视觉验收。
