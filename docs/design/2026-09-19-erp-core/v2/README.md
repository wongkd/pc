# E01 · ERP 核心四屏交互原型 v2

日期：2026-09-19。状态：可点击演示原型，等待用户视觉与操作评审；不接生产接口。

## 入口与运行

- 入口：`index.html`；推荐通过本地静态服务访问 `/v2/`。
- 命令：`node docs/design/2026-09-19-erp-core/v2/serve.cjs`
- 地址：`http://127.0.0.1:8830/v2/`
- 停止：在运行命令的终端按 `Ctrl+C`。

## 本轮范围

- 工作台：待办优先、今日交付、缺件/待收款/异常筛选与右侧处理区。
- 报价编辑：预算、逐行单价、来源/质保、客供件、临时报价行、定金/尾款、配送待核价、顾客预览和打印配件单。
- 订单详情：配置→备货→检测→交付阶段、缺件跟进、收款待核实、检测清单和交付核对。
- 库存：型号表、可用/预留/待处理/在途/客户保管、SN/来源/质保/成本权限与实物抽屉、现买现入预览。
- 场景选择器：空状态、加载/保存失败、无成本权限、收款结果待核实、长型号/大金额。

全部金额、客户、库存和交付均为虚构演示数据；按钮只改变本地页面状态，不能创建真实收款、采购、库存流水或订单。图片是 AI 类别示意，不是实物证据。

## 文件职责

| 文件 | 职责 |
|---|---|
| `index.html` | 原型入口与对话框容器 |
