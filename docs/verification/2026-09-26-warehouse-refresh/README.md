# 仓库体验与库存登记生产发布

- 日期：2026-09-26
- 状态：已部署生产 Worker `eee68a74-de11-4774-a60c-cdd473bffa63`，部署列表确认流量 100%。
- 入口：ERP → 仓库 → 新增商品 / 记录实盘数量 / 操作日志。

## 本轮变更

- 新增商品分类改为固定下拉；选择“其他（自定义）”时显示自定义分类输入框。
- 期初区域改为“系统启用前 · 一次性登记 / 录入系统启用前已有库存”；说明负责人开启后可在所选期限内按盘点资料录入，首笔日常库存业务或到期后自动关闭且不能重开。
- 库存盘点入口改为“记录实盘数量”。表单说明实盘数用于与账面数量对照，保存只记结果，不直接改库存；差异须经批准后入账。
- “实物流转”导航统一改为“仓库”。新增库存视图权限成员可见的最近 50 条操作日志，默认折叠、展开时读取；不返回成本字段。
- 补齐桌面和窄屏样式，期初信息独立成卡，避免把新增商品、窗口期限、开启和盘点动作挤在一行。
