- 日期：2026-09-25
- 状态：本记录所列浏览器操作与刷新回读完成；发布候选整体验收仍未通过。
- 目标：补齐销售到交付、售后处理、回收验机与折抵、客户新增/编辑及刷新回读，以及有业务单据时的失败恢复。
- 基线记录：[发布候选整体验收矩阵](../2026-09-25-release-candidate-acceptance/README.md)。本记录补充其中缺项，不覆盖原始记录。

## 环境与方法

- 使用同一个本地 Worker（`127.0.0.1:8879`）和一份 Miniflare 内存 D1；Vite 网页（`127.0.0.1:5181`）代理到该 Worker。整轮业务写入均从 Edge 浏览器页面操作，操作后在页面查看结果，并对客户、售后、交付及折抵结果执行整页刷新后回读。
- 启动方式：`PORT=8879 node scripts/dev-server.mjs`；`VITE_API_TARGET=http://127.0.0.1:8879 npm run dev -- --host 127.0.0.1 --port 5181 --strictPort`。
- 所有顾客、设备、单据、价格和收款均为本地合成验收数据；收款为模拟收款，不触发真实支付，不代表取得或交付真实硬件。Worker 停止后内存 D1 会清空。
- 这是本地浏览器操作证据；组件测试和 HTTP 测试没有替代本轮操作。未部署、未迁移远端、未读写生产。
