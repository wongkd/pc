## 本地实现与浏览器证据

- U03 仓库按配件类别查看逐件库存与数量库存，独立追加分页；登记表默认二手、逐件、数量 1，同一流程复用 / 创建型号并补录库存。网络失败保留输入，未知写入结果按原 requestId 查询，成功行不重复提交。
- U04 采购到货草稿可带入型号、数量、成色、厂家编号和说明；回收草稿可带入类别、型号、SN 与状况；报价可按分类寻找可售实物，并从库存详情选择指定实物进入报价。历史检测状态未记录、但已经可售的实物会进入报价流程，不会被错误导向检测。
- 浏览器连接本地真实 Worker 与内存 D1（`backend/scripts/dev-server.mjs`），只使用合成演示数据。键盘登记并回读 `U03 键盘验收 Ryzen 5 5600G`，核对 1 件库存、待检测 / 待处理状态、库存流水和 B47 来源批次 / 行；厂家编号读回正常，成本未知显示“待确认”。该记录随本地进程退出而消失，不涉及线上环境。
- 约 480px 窄屏与 2560×1306 桌面视口均查看仓库页面；来源编号折叠区、分类列表、库存状态、成本及下一动作可辨认。本轮未留存浏览器截图。
- 完整键盘路径发现登记弹窗未接管 Tab 焦点，现已补首字段聚焦、弹窗内 Tab 循环和关闭后焦点归还，并以浏览器逐字段完成登记验证。采购转办表单显示可读的类别 / 型号名称，内部 productRef 不再占据主视图；验证了回收与采购草稿预填，但没有创建采购单或回收单。真实员工会话尚未验收。
- 文案检查移除了报价 / 回收页面面向店员展示的整数分实现说明，未知成本输入错误改为按金额说明。
