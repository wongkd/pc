## 环境异常与定位

- 最初访问 5174 时，库存在请求完成前显示空态；菜单交互后库存正常出现。采购用同页商品 SKU 提交却返回“不存在”，随后确认 5174 上已有服务连接另一内存库（8787 监听冲突），前后端数据不共享。该次错误采购未创建业务记录，表单保留。
- 用独立 Worker 8878 与临时 Vite 配置将代理绑定到同一内存库后，页面重新干净登录，空列表验证正常。报价页在 5174 创建/发出的临时报价只属于原服务的内存库，服务未由本轮启动，未尝试停掉用户已有 8787/5173 服务。
- 独立 8878 环境验证“创建邀请但不指定角色 → 接受邀请”返回 409「邀请角色不可用」。源码在未传 `roleId` 时会从邀请所属门店读取 `code='sales'`；旧临时 D1 已删除，无法再核实当时角色行是否存在。该 409 与缺少门店角色种子相符，单凭它不能证明邀请代码有缺陷。旧环境只因此未完成员工浏览器验收；后续本地种子与 HTTP 复验见[员工权限复验](../2026-09-25-staff-permissions/README.md)。
- 远端隔离预览仍是旧前端包；本轮未部署、未迁移远端，生产未触碰。
