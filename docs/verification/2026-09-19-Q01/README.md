```powershell
node docs/design/2026-09-19-customer-quote/v1/verify.cjs
```

覆盖内容：

1. **布局**：320 / 375 / 390 / 430 / 768 / 1366 / 1440 七个视口，页面、手机框、报价页三层都无横向溢出；1366×768 主动作在首屏。
2. **状态**：10 个状态逐一用链接形态打开（`#/q/...&state=...`），确认控制台隐藏、无溢出、标题文案正确。
3. **信息隔离（本卡核心断言）**：`auth` / `forbidden` / `notfound` / `loading` / `error` / `withdrawn` 六态
   页面文本内**不含 `¥`、不含配件名、不含型号、不含「预算」字样**。
4. **单价明细**：12 行（10 件硬件 + 2 项服务）；每行都匹配 `¥单价 × 数量` 与小计格式；客供件为 `¥0.00`；
   二手件带「本店二手 / 质保 3 个月」，客供件带「顾客自带 / 不提供质保」。
5. **金额口径**：配件合计 ¥8,799.00、服务 ¥350.00、优惠 −¥500.00、应付 ¥8,649.00、定金 ¥1,297.35、尾款 ¥7,351.65；
   并核对两条恒等式：配件 + 服务 − 优惠 = 应付，定金 + 尾款 = 应付。
6. **付款未接通**：点付款弹出说明层，标题「支付尚未接通」，正文含「不会发起真实微信支付」。Escape 可关。
7. **键盘**：聚焦付款方式后按空格可切换单选；主按钮金额随选择变化。
8. **版本分支**：`updated` 态主按钮禁用并提示先看最新版；点「查看最新版本」后进入 v3，应付变 ¥8,749.00 且恢复可付款。
9. **异常分支**：`expired` 保留 12 行明细但禁止付款；`deposit` 禁止重复支付并标注「不是真实到账」。
10. **内部信息不泄漏**：valid / expired / updated / deposit 四态文本均不含「成本」「供应商」「进价」「毛利」「其他顾客」，
    且全文不含「订金」。
11. **链接互转**：控制台给出带凭证与状态参数的专属链接；打开后控制台隐藏；切状态时链接参数同步更新。
12. **预算对照条**：预算 ¥12,000 时写「比预算低 ¥3,351.00」、进度 72.1%、不用警示色；
    切到 ¥8,000 时写「超出预算 ¥649.00」、进度封顶 100%、转警示色；
    进度条带无障碍描述；文案不含「省」字；`expired` / `updated` / `deposit` 三态保留对照条；
    320px 最窄视口下「本单」与结论仍在同一行。
13. **预算维度独立**：控制台切换预算档会写进链接参数 `budget`，且**不会把正在看的版本重置回 v2**。

## 本轮修掉的问题

| 问题 | 处理 |
|---|---|
| 浏览器自动请求 favicon 得到 404，被记为运行时错误 | 补内联 SVG 图标，不用白名单绕开 |
| 报价头部日期被断行成「2026-09-」/「19」 | 日期片段加 `white-space: nowrap` |
| 明细表头写「单价为含税价」，对个体工商户口径不适用 | 改为「共 12 项」 |
| 长图只截到视口高度（`.stage` 自带滚动） | 截图时临时解开 `html/body/.stage/.device` 高度，只作用于截图 |
