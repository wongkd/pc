## 集成发现与修复

首次总链在“顾客确认报价 → 转销售单”失败。`B03` 只把报价状态从 `confirmed` 改为 `converted`，但 0012 的表约束规定 `confirmedAt / confirmedSource` 仅在 `status=confirmed` 时允许存在，因此整个转单事务回滚。

修复位于 `backend/src/domains/sale.ts`：同一条条件更新在转为 `converted` 时清空状态专属确认字段。B42 的确认事实仍由幂等操作结果与版本日志追溯；未修改契约、既有迁移或后端入口。
