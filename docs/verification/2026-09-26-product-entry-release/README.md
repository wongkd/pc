# 商品建档与初始库存入口生产发布回执

- 日期：2026-09-26
- 状态：商品建档界面已发布到生产 Worker；生产页面资源核对通过。未做登录后业务验收。
- 目标：简化新增商品表单，默认建立并启用商品；可在同一表单填写系统启用前已有库存及其盘点、成本凭据。
- 入口：ERP `https://erp.huangqidong.cn/`，库存页 → 新增商品。
- 基线：`v2-2026-09-26`，提交 `534248f`。

## 发布内容

- 新增商品字段顺序为分类、品牌、商品名称、SKU、参考售价、规格说明、管理方式、数量。
- 新建商品默认启用，不再要求用户选择商品状态；编辑商品仍可更改启用状态。
- 数量为 0 时仅建档；数量大于 0 时，在本表单补充实盘凭据、成本口径及对应依据，再调用正式期初库存登记。
- 商品建档和库存登记仍由现有服务端接口执行；初始库存受正式期初窗口、权限和凭据守卫约束。
- 部署以生产 V2 基线为基础，只带入 `WorkbenchInventoryPage.tsx` 和对应测试文件的本轮改动。其他工作区中的管理员清理、契约和后端脏改动没有发布。
