# N19-N26 多 SKU 候选商品选择 — 完成概览

## 做了什么

硬件库查价（🔍 查价 / 🔄 单条刷新）现在支持多候选商品选择：
- 查价返回 ≥2 条时弹出候选卡片弹窗
- 用户可浏览、比较、改选后确认写入
- 取消则不写入任何数据

## 行为矩阵

| 场景 | 0 条 | 1 条 | ≥2 条 |
|------|------|------|------|
| 🔍 查价（新增硬件） | 红色提示"未找到" | 自动填充 | **弹候选框** |
| 🔄 单条刷新 | 静默跳过 | 自动更新 | **弹候选框** |
| ⚡ 一键比价（批量） | 跳过 | 自动选最优 | **自动选最优** |

## 候选弹窗功能

- 按关键词匹配度 + 平台 + 销量评分排序
- 首项标记"推荐"并默认选中
- 显示：商品图、标题、平台、店铺、实时/原价/券后价、月销量
- 图片缺失→"暂无图片"，价格缺失→"暂无报价"
- 点击卡片切换选择，蓝色边框高亮当前选中
