## 5. 已知边界情况

| 问题 | 说明 |
|------|------|
| 旧模板不含配置数据 | 修复前保存的模板只有品牌信息，旧模板需删除后重新保存。 |
| 浏览器打印页眉页脚 | 浏览器自带页眉、页脚、网址和页码由打印设置控制，网页只能处理主体撑页。 |
| 本地新增硬件库条目无 cloudId | 在硬件库界面手动新增的条目没有 cloudId（未即时同步），但不影响从硬件库添加已有条目的同步。 |

## 6. 常用验证命令

前端构建：

```bash
cd frontend
npm run build
```

当前环境可直接用本地 Node 执行：

```bash
cd frontend
C:/Users/宋黄金/.workbuddy/binaries/node/versions/22.22.2/node.exe ./node_modules/typescript/bin/tsc -b
C:/Users/宋黄金/.workbuddy/binaries/node/versions/22.22.2/node.exe ./node_modules/vite/bin/vite.js build
```

前端部署：

```bash
cd frontend
wrangler pages deploy ./dist --project-name pc-quote --branch main
```

后端部署：

```bash
cd backend
wrangler deploy
```
