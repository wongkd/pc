## 4. 待办详情

### N1-N7：条款与备注四个框内容可编辑

目标：报价单预览中的「付款方式 / 售后说明 / 质保政策 / 备注条款」四个框要能分别编辑，并参与保存、模板、导出。

要做：

| 编号 | 任务 |
|------|------|
| N1 | 梳理四个框当前数据来源。 |
| N2 | 拆成四个可编辑字段。 |
| N3 | 保持四宫格展示效果。 |
| N4 | 跟随报价单本地和云端保存。 |
| N5 | 跟随商家模板保存和套用。 |
| N6 | 兼容旧报价单和旧模板，缺字段用默认文案。 |
| N7 | HTML / PNG / PDF 导出使用编辑后的内容。 |

不允许：不改硬件配置、价格计算、登录权限、硬件库查价；不破坏原四宫格视觉。

验收：四个框分别修改后预览立即更新；刷新和跨设备恢复；模板保存/套用恢复；导出一致；旧模板不报错。

| N9 | 手动新增硬件时规格为空。 |

| N11 | 保留用户已填写规格。 |
| N12 | 兼容旧报价单和旧模板。 |

不允许：不清空历史规格；不影响硬件信息、价格、硬件库数据、导出排版。

验收：新增、硬件库添加、查价添加、一键比价添加后规格为空；手动填写后保存/刷新/模板/导出都保留。
